BACK UP the last working AwaazAI folder before switching.

1. Extract the ZIP to Desktop. Open the enclosed AwaazAI_Pro folder in VS Code.
2. In VS Code Terminal, run:
       python -m pip install -r requirements.txt
       python -m streamlit run app.py
3. Open the Local URL that appears in terminal (normally http://localhost:8501).
   If a previous Streamlit project is running, stop it via Ctrl+C first.
4. Gemini key: keep GEMINI_API_KEY in your Windows environment or Streamlit Cloud secrets.
   Never paste an API key into app.py or a public GitHub repository.
